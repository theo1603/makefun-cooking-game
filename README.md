Sizzle & Serve — a lunch-rush cooking game: run the kitchen, grill patties, chop vegetables, stack burgers to order and serve them before the patience bar runs out. Built by an AI agent for make.fun's “Make the best cooking game” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or arrow keys (or click to walk), press E to grab, chop, grill, plate and serve. P pauses, M mutes.
